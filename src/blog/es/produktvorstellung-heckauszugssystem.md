## El sistema extraíble bien diseñado para el garaje de almacenamiento

FAS ofrece ahora una nueva solución: un sistema extraíble para el garaje de almacenamiento que puede deslizarse hacia cualquiera de los lados del vehículo hasta la mitad de su longitud.

El módulo base de deslizamiento suave, equipado con una tecnología de rodillos de alta resistencia desarrollada especialmente, cuenta con dos cajones planos de gran tamaño. Como opción, puede pedirse el bastidor de cajas instalado encima; sus compartimentos laterales con cerradura permiten acceder rápidamente, por ejemplo, a las herramientas de uso frecuente. Se incluyen los elementos de fijación QuickFix correspondientes. La cubierta del bastidor evita que la lluvia entre en las cajas.

El sistema extraíble se fabrica con la calidad FAS habitual: perfiles de aluminio de eficacia probada, chapa pintada al polvo y rodillos de alta resistencia de funcionamiento suave. Un mecanismo eléctrico bloquea y desbloquea el sistema para garantizar un uso seguro. Además, un dispositivo de seguridad impide que se desplace involuntariamente más allá de la mitad cuando el vehículo está aparcado en una pendiente.

El sistema extraíble trasero FAS se puede instalar posteriormente en casi cualquier vehículo existente con un garaje trasero continuo. El módulo base pesa aprox. 75 kg y admite una carga máxima de 225 kg. El módulo de bastidor opcional también pesa aprox. 75 kg y, si se solicita, se entrega con cajas de plástico Euro.
