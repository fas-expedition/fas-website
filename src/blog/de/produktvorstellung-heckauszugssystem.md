## Das durchdachte Auszugsystem für das Garagenstaufach

Ein neues Feature ist ab sofort bei FAS erhältlich: Ein Auszugsystem für das Garagenstaufach, das zu beiden Fahrzeugseiten jeweils bis zur Hälfte ausgefahren werden kann.

Das leichtlaufende Grundmodul mit speziell entwickelter Schwerlastrollentechnik ist mit zwei großen flachen Schubläden ausgestattet. Optional kann das darüber installierte Boxenrack dazu bestellt werden, dessen seitliche abschließbare Compartments den Schnellzugriff auf zum Beispiel häufig benötigtes Werkzeug ermöglichen - entsprechende QuickFix-Befestigungen werden mitgeliefert. Die Deckplatte des Racks verhindert das Eindringen von Regenwasser in die Boxen.

Das Auszugsystem ist in gewohnt hoher FAS-Qualität gefertigt: erprobte Aluminiumprofile, pulverbeschichtete Bleche, leichtgängige Schwerlastrollen. Für die sichere Bedienung sorgt eine elektrische Ver-/Entriegelung sowie eine zusätzliche Schutzinstallation, die eine ungewollte Verschiebung über die Hälfte hinaus bei abschüssiger Parkposition verhindert.

Das FAS-Heckauszugsystem kann in fast jedem Bestandsfahrzeug mit durchgehender Heckgarage nachgerüstet werden. Das Grundmodul hat ein Eigengewicht von ca. 75kg und kann mit max. 225kg belastet werden. Das optionale Rack-Modul wiegt ebenfalls ca. 75kg und wird auf Wunsch inkl. Euro-Kunststoffboxen geliefert.
